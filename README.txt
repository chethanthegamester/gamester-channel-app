GAMESTER CHANNEL APP — QUICK START

WHAT THIS IS
A polished, installable Progressive Web App (PWA) companion for the YouTube channel URL you supplied. It includes a home screen, links to videos and Shorts, an embedded uploads playlist, and an install button when supported.

IMPORTANT
This is not yet a native APK and it is not published in Google Play. It is an installable app-style experience that runs on Android and desktop browsers. YouTube playback needs an internet connection. The embedded uploads playlist depends on YouTube exposing the channel's uploads playlist.

HOW TO PUBLISH IT FREE WITH GITHUB PAGES
1. Extract the ZIP.
2. Open your GitHub repository (you can use a new repository named gamester-channel-app).
3. Upload index.html, manifest.json, sw.js, icon.svg and README.txt to the repository root.
4. In GitHub, open Settings → Pages.
5. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
6. Wait for the published URL shown in GitHub Pages.
7. Open that URL on Android in Chrome. Use the browser menu → Install app or Add to Home screen.

ON DESKTOP
Open the published URL in Chrome or Edge. Use the install icon in the address bar or the app's Install App button if shown.
